# 高清资源目录

`/hd` 独立于首页推荐和普通点播搜索，当前仅展示人人电影（rrdynb.com）、HDzone（hdzu.org）。用户要求移除不可用入口后，银盘、一楼不再展示或发起请求；不向目录补入其他播放源。

- `/api/hd-resources` 沿用 HomeTV 登录验证，只接受当前启用站点中已支持的目录/详情路径，每次重定向都重新检查域名、路径和公网地址。
- 每站独立请求、失败可重试；成功结果缓存十分钟，失败不缓存。读取上限 2 MB、请求超时 16 秒，不执行源站脚本。
- 目录包含源站标题及介绍，详情展示公开可提取的磁力、种子、网盘和文件链接；网盘可打开，其他链接可复制到对应下载工具。
- 需要登录原站的详情明确提示用户到原站登录，不采集站点账号，不自动下载资源。
- 当前 iOS HLS/MP4 离线下载不支持直接处理磁力、BT、网盘或蓝光原盘；资源目录不会将这些链接交给原生播放器或下载管理器。
