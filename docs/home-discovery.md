# 精选首页

首页默认依次展示当前成员续看、每日精选、本周专题和原推荐数据源。设置 → 首页与内容过滤 → 首页布局可切回原榜单首页；推荐来源设置仍然有效。

每日精选按北京时间、目录版本、成人过滤开关生成三组不重复的 12 部影片。有评分的影片需达到 7 分；没有评分时仍可按精选片单入选，不生成虚构评分。每组先显示六部，同演员最多三部、同导演和同系列最多两部，并优先分散类型和年代。各 AI 种子的候选交替加入，每组最多四部 AI 候选。专题每周一轮换。没有可续播记录时不展示续看；单集已完成但剧集未完时跳转下一集。

## DeepSeek

复用 `DEEPSEEK_API_KEY` 和 `DEEPSEEK_RECOMMEND_MODEL`。已登录用户首次访问 `/api/home/recommendations` 时立即返回本地精选，通过 Next.js `after()` 在响应后生成 AI 扩展。每天每个过滤版本最多三个种子、两次尝试；同进程并发访问共享任务，失败后至少等待五分钟。现有 DeepSeek 客户端另外提供单作品 24 小时缓存与全局两请求并发上限。

仅发送精选种子的片名、年份与公开影片资料，不读取或发送成员观看历史。AI 候选必须匹配目录中的片名与年份，元数据、封面取自目录；不能确认的作品舍弃。首页海报卡不预查片源，用户打开详情才复用分批片源匹配及播放器。

每日结果写入 `HOME_RECOMMEND_CACHE_DIR`，默认系统临时目录下 `hometv-home-recommendations`，只有两个 JSON 文件（按成人过滤区分），原子覆盖。服务进程需要目录写权限；无法写入时回退进程内缓存。部署时可配置持久目录避免主机重启清理临时文件后重新生成。当前单 Node 实例适用；多进程部署应改为共享任务锁和缓存。

AI 请求失败、无密钥或无核验通过的作品时继续显示本地精选。页面轮询后台任务完成状态，缓存当日最终结果；北京时间跨日自动刷新。热榜失败时最多沿用七天内的进程内成功结果，显示北京时间更新时间，冷启动无缓存时展示原失败提示。

## 验证与回退

测试覆盖北京时间午夜、每日稳定性、批次去重与多样性、AI 身份核验、内容过滤、缓存恢复、并发去重、限次重试、接口认证、续看与下一集、热榜失败恢复。发布运行 lint、类型检查、全量测试和生产构建，并检查手机布局、详情和榜单入口。

首页布局设置可即时回到原榜单。撤回版本可沿用现有发布流程激活上一份构建，不需要数据库迁移；本次没有改变成员历史或同步格式。
